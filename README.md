# Futuro Administrador

Jogo 2D (PWA) do **Curso de Administração do ISE**: o aluno corre pelo corredor da faculdade, coleta 15 disciplinas, desvia de reprovações, festas e bebidas, e recebe o diploma na Colação de Grau.

- Feito para monitor (16:9) e **jogado só pelo teclado**: setas ← → trocam de faixa, Enter confirma, P pausa.
- Funciona offline depois do primeiro acesso e pode ser instalado como app (PWA).

## Rodar localmente

Dê dois cliques em `Iniciar Jogo.bat` (Windows) ou rode `node server.js` e abra o endereço mostrado.
